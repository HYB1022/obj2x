# obj2x

Blender에서 내보낸 **obj → x → o3d** 변환을 폴더 단위로 한 번에 처리해 주는 OMSI용 도구입니다.
파일을 하나씩 열고 옵션을 맞추고 Convert를 누르던 작업을, 폴더만 지정하면 자동으로 해 줍니다.

## 하는 일

1. 폴더 안의 `.obj`를 Blender 2.79로 `.x`로 변환합니다.
2. 변환된 `.x`를 OmsiXConv로 `.o3d`까지 변환합니다. OmsiXConv의 체크박스(`X-File: z up` 등)는 설정한 상태로 자동으로 맞춰 줍니다.
3. OmsiXConv를 여러 개 동시에 띄워 병렬로 처리하고, 그 창들은 화면 밖으로 치워서 이 도구의 창만 보이게 합니다.
4. **[내장 빠른 변환 Engine]** Blender나 OmsiXConv 없이 `.obj`에서 바로 `.o3d`를 즉시 생성하는 고속 변환을 지원합니다.

`.o3d`는 `.x`와 같은 폴더에 생기며, 파일 이름은 obj 이름과 같습니다 (`face.obj` → `face.x` → `face.o3d`).

## 필요한 것

| 필요한 것 | 설명 |
| --- | --- |
| Windows 10 / 11 | PowerShell 5.1 이상 기본 포함 (따로 설치할 필요 없음) |
| [Blender 2.79b](https://download.blender.org/release/Blender2.79/) | **(기존 변환 방식 시 필요)** `Import-Export: DirectX X Format` 애드온 활성화 필요. 2.8 이상은 미지원. |
| OmsiXConv (Omsi X to O3D Converter 1.0) | **(기존 변환 방식 시 필요)** 이 저장소에 포함되어 있지 않습니다. 별도로 구해서 `OmsiXConv.exe` 위치를 지정하세요. |

> **참고**: 내장 **빠른 변환** 기능을 사용할 경우 Blender 2.79b 및 OmsiXConv가 없어도 `.obj`에서 바로 `.o3d` 생성이 가능합니다. obj를 생성하는 Blender 버전은 제한이 없습니다.

## 사용법

1. [Releases](https://github.com/HYB1022/obj2x/releases)에서 최신 `obj2x.zip`을 받아 **쓰기 가능한 폴더**에 풉니다. 설정은 같은 폴더의 `obj2x.ini`에 저장됩니다.
2. `obj2x.bat`을 실행합니다.
3. 아래 항목을 지정합니다. (한 번 지정하면 자동으로 저장됩니다)
   - **OBJ 폴더 경로**: 폴더나 `.obj` 파일을 경로 입력창에 Drag & Drop 하셔도 됩니다.
   - **Blender 2.79 / OmsiXConv 경로**: 기존 방식을 사용할 경우 각 `.exe` 파일 위치를 지정합니다.
   - **출력 폴더**: `입력 폴더와 같게`를 체크하면 같은 위치에 생성됩니다.
4. `변환 시작`을 누릅니다. 진행 상황이 하단 로그 창에 표시됩니다.

> OmsiXConv를 통한 병렬 변환 도중에는 화면 밖의 백그라운드 창이 키/마우스 입력을 받을 수 있으므로 가급적 마우스와 키보드 조작을 자제해 주세요.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| **빠른 변환 (내장 FastO3D)** | 체크 시 Blender/OmsiXConv 없이 obj에서 즉시 `.o3d`를 생성합니다 (파일당 0.1초 안팎). OBJ 입력 폴더만 지정하면 변환됩니다. |
| **하위 폴더 포함** | 입력 폴더 내의 모든 하위 폴더를 탐색하여 `.obj`를 변환하며, 출력 폴더에도 동일한 폴더 구조를 유지합니다. |
| **변경된 obj만 변환** | `.o3d` (또는 `.x`) 파일보다 최근에 수정된 `.obj` 파일만 감지하여 변환합니다. 모델링 반복 작업 시 유용합니다. |
| **중지 / 실패건 재시도** | 작업 진행 중 전체 프로세스를 강제 종료하거나, 실패한 파일만 골라 O3D 단계부터 다시 변환할 수 있습니다. |
| **동시 실행 (병렬 처리)** | PC의 논리 코어 수에 맞추어 OmsiXConv 병렬 쓰레드 수를 자동 제어합니다 (기본값: 코어 수 - 1). |
| **옵션 설정** | OmsiXConv의 8가지 체크박스 옵션, 변환 성공 후 `.x` 중간 파일 자동 삭제, Blender Exporter 추가 옵션 등을 설정할 수 있습니다. |
| **자동 업데이트** | 앱 시작 시 GitHub 최신 Release를 검사하여 설정 유지 및 백업 후 자동 업데이트를 수행합니다. |

### 빠른 변환 (FastO3D) 안내

FastO3D 엔진은 OmsiXConv의 포맷 구조를 분석하여 직접 `.o3d` 바이너리를 구축하는 고속 변환기입니다.

* **장점**: Blender 실행 및 GUI 훅킹 오버헤드가 없어 정점/삼각형 개수가 많은 작업도 비약적으로 빠르게 처리됩니다.
* **주의 사항**:
  * 단일 메쉬 단위 처리에 최적화되어 있으며, 정점(Vertex) 및 삼각형(Triangle) 수가 **65,535개**를 초과하는 모델은 안전을 위해 변환이 제한됩니다.
  * OmsiXConv 전용 UI 옵션(`z up` 등)이나 Blender 내보내기 옵션은 내장 FastO3D 모드에서 적용되지 않습니다.
  * `.mtl` 재질 파일이 없거나 누락된 매핑이 있는 경우 로그 창에 `[주의: ...]` 형태로 안내 메시지가 출력됩니다.

## 업데이트 및 백업

시작 시 새 버전이 탐지되면 업데이트 여부를 묻습니다.
- **자동 설치 진행 시**: 최신 패키지를 다운로드하여 현재 폴더에 덮어씁니다.
- **안전한 백업**: 기존 `obj2x.bat`, `obj2x_gui.ps1`, `obj2x.py`는 `obj2x_backup` 폴더에 버전별로 자동 보관됩니다.
- **설정 유지**: 사용자 설정 파일(`obj2x.ini`)은 초기화되지 않고 유지됩니다.

## 문제 해결

| 증상 | 조치 방법 |
| --- | --- |
| **Windows 스마트스크린/보안 경고** | `.bat` 및 `.ps1` 기반 스크립트이므로 소스를 직접 확인할 수 있습니다. '추가 정보' -> '실행'을 클릭하세요. |
| **`blender.exe` 경로 오류** | Blender 2.79b의 실행 파일 경로가 올바른지 확인하세요. |
| **`E/A-Fehler 103` 에러 발생** | OmsiXConv 처리 과정의 간성 오류입니다. 자동 재시도(최대 3회)하며, 계속 발생 시 '동시 실행 개수'를 줄여주세요. |
| **창/파일 선택창 탐색 실패 로그** | 백그라운드 작업 창을 방해하는 타 프로그램이 없는지 확인하고, 계속 발생 시 로그 내용을 이슈로 작성해 주세요. |
