# obj2x

Blender에서 내보낸 **.obj → .x → .o3d** 변환 과정을 직관적인 GUI 화면으로 한 번에 관리하고 일괄 처리해 주는 OMSI용 전용 개발자 도구입니다.

> 💡 **GUI 디자인 참조**  
> 본 프로젝트의 GUI 레이아웃 및 사용자 환경(UX) 디자인 구조는 [miner7222/LTBox](https://github.com/miner7222/LTBox)의 직관적이고 깔끔한 그래픽 인터페이스 구조에서 영감을 얻어 제작되었습니다.

---

## 📱 GUI 인터페이스 주요 구성

`obj2x`의 graphical interface는 복잡한 CLI(명령줄) 명령어나 파이썬 스크립트 실행 없이, 사용자가 필요한 옵션만 클릭하여 손쉽게 변환 작업을 수행할 수 있도록 설계되었습니다.

* **경로 설정 및 Drag & Drop 영역**: 
  - `Blender.exe`, `OmsiXConv.exe` 실행 경로 설정
  - **OBJ 입력 폴더 드래그 앤 드롭 지원**: 폴더나 파일(.obj)을 입력 칸으로 끌어다 놓으면 경로가 즉시 입력됩니다.
  - **입력 폴더와 같게**: 클릭 한 번으로 출력 폴더를 입력 폴더 경로와 자동으로 일치시킵니다.
* **직관적인 모드 전환 및 옵션 체크박스**:
  - **빠른 변환 (FastO3D)**: 외부 프로그램 없이 내장 엔진으로 즉시 변환하는 모드 (선택 시 관련 없는 설정 칸은 자동으로 비활성화 처리됨)
  - **하위 폴더 포함 / 변경된 obj만 변환**: 원하는 처리 범위만 체크박스로 간단히 선택
  - **OmsiXConv 동시 실행 (병렬 수)**: Numeric Control을 통해 내 PC의 논리 코어 수에 맞춘 병렬 처리 수를 손쉽게 조정
* **상세 옵션 모달 창 (GUI 옵션)**:
  - OmsiXConv의 8가지 체크박스 옵션(`z up`, `Remove Specular`, `Opt. Vertices` 등)을 화면에서 직접 클릭하여 설정
  - 변환 완료 후 `.x` 중간 파일 자동 삭제 여부 선택
  - Blender Exporter에 전달할 추가 옵션(`ApplyModifiers=True` 등)을 텍스트 상자에 한 줄씩 입력 가능
* **실시간 실시간 작업 로그 & 진행 컨트롤**:
  - 하단 로그 화면(Console Box)을 통해 파일별 변환 성공/실패 여부, 소요 시간, 주의(Warning) 메시지 실시간 확인
  - **[변환 시작] / [중지] / [실패한 것만 다시]** 컨트롤 버튼으로 안정적인 작업 관리
* **자동 업데이트 알림 링크**:
  - 창 하단에 현재 버전 표시 및 GitHub Releases 연동을 통해 새 버전이 출시되면 클릭 한 번으로 자동 백업 후 업데이트 수행

## 🛠️ 지원하는 변환 모드

### 1. GUI 내장 고속 변환 (FastO3D)
* Blender 및 OmsiXConv 프로그램 없이, GUI 자체 내장 분석 엔진을 통해 `.obj`에서 바로 `.o3d`를 즉시 생성합니다.
* 파일당 **0.1초 안팎**의 압도적인 속도를 자랑합니다.

### 2. 표준 파이프라인 변환 (Blender 2.79 + OmsiXConv)
* 폴더 내의 `.obj`를 지정한 Blender 2.79를 통해 `.x`로 일괄 내보내기합니다.
* 변환된 `.x` 파일을 설정한 병렬 수만큼 백그라운드 OmsiXConv 프로세스로 띄워 GUI 설정값에 맞춰 `.o3d`로 병렬 변환합니다.

## 📋 준비물

| 항목 | 설명 |
| --- | --- |
| **OS** | Windows 10 / 11 (PowerShell 5.1 이상 기본 포함) |
| **[선택] Blender 2.79b** | **(표준 변환 방식 사용 시)** `Import-Export: DirectX X Format` 애드온 활성화 필요 (2.8 이상 미지원) |
| **[선택] OmsiXConv** | **(표준 변환 방식 사용 시)** 별도 구비 후 GUI 상에서 `OmsiXConv.exe` 위치 지정 |

> ※ 내장 **빠른 변환** 모드를 사용할 경우 Blender 및 OmsiXConv 없이도 동작합니다.

## 🚀 시작하기

1. [Releases](https://github.com/HYB1022/obj2x/releases)에서 최신 `obj2x.zip`을 다운로드한 후 쓰기 가능한 폴더에 압축을 풉니다.
2. `obj2x.bat`을 실행하여 GUI 창을 엽니다.
3. GUI 화면에서 **OBJ 폴더 경로**를 지정하거나, 폴더를 GUI 창으로 Drag & Drop 합니다.
4. 필요에 따라 `빠른 변환` 모드를 체크하거나 표준 변환용 `.exe` 경로를 지정합니다.
5. **[변환 시작]** 버튼을 클릭하면 하단 로그 창에 실시간 진행 상황이 표시됩니다.

## ⚙️ 주요 GUI 기능 명세

| GUI 기능 요소 | 설명 |
| --- | --- |
| **입력 Drag & Drop** | 폴더 또는 `.obj` 파일을 경로 창에 끌어놓아 입력 |
| **빠른 변환** | 내장 FastO3D 엔진 사용 (체크 시 불필요한 입력 요소 자동 비활성화) |
| **하위 폴더 포함** | 입력 폴더 하위의 모든 `.obj` 파일 및 폴더 구조 유지 변환 |
| **변경된 obj만 변환** | 최근 수정된 `.obj` 파일만 탐지하여 시간 단축 |
| **옵션... 버튼** | OmsiXConv 8개 체크박스 및 `.x` 자동 삭제, Blender 추가 옵션 설정 모달 열기 |
| **실패한 것만 다시** | 전체 작업 후 오류가 난 파일만 감지하여 O3D 단계부터 재시도 |
| **시작 시 업데이트 확인** | 최신버전 탐지 시 클릭하여 자동 설치 및 기존 스크립트 자동 백업(`obj2x_backup`) |

## ❓ 문제 해결

| 증상 | 조치 방법 |
| --- | --- |
| **Windows 스마트스크린 경고** | 오픈소스 스크립트 기반 실행 파일입니다. '추가 정보' -> '실행'을 클릭하세요. |
| **`blender.exe` 오류** | 표준 변환 방식 사용 시 Blender 2.79b 버전의 `blender.exe` 경로가 올바른지 확인하세요. |
| **`E/A-Fehler 103` 발생** | OmsiXConv 처리 중 발생하는 에러입니다. 자동으로 재시도되며, 지속 발생 시 GUI의 동시 실행 수를 줄여주세요. |
